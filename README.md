# Curio Market

Curio Market 是一个面向海外消费者的商品发现与选购 Web 应用。项目以“少而精”的策展式购物体验为核心，通过清晰的商品信息、轻量的筛选流程和完整的购物车交互，帮助用户快速找到值得购买的商品。

在线演示地址：https://jeff-jayden.github.io/Presence_review/

## 项目定位

传统电商平台通常依赖大量 SKU、复杂导航和密集促销。Curio Market 采用更克制的产品策略：

- 用编辑精选降低用户的选择成本
- 在首屏明确传达品牌定位、全球配送和退货保障
- 将搜索、分类、排序、商品详情和加购组织成连续的购买路径
- 通过统一的图片比例、字体层级和留白塑造海外生活方式品牌的视觉感受
- 优先完成适合客户演示的核心购物闭环

## 核心功能

- 商品关键词搜索与无结果提示
- Tech、Home、Travel、Style 分类筛选
- Featured、Top rated、Price 排序
- 商品收藏及收藏数量提示
- 商品详情弹窗、评分、库存与配送信息
- 商品快捷加购
- 购物车抽屉、数量调整和金额汇总
- 桌面端、平板和移动端响应式布局
- 模拟商品数据，无需后端服务即可运行

## 技术栈

- React 19
- TypeScript
- Vite 8
- Ant Design 6
- Ant Design Icons
- ESLint
- CSS 响应式布局

项目为纯前端单页应用，不包含 Next.js、服务端渲染、数据库、登录、真实订单或支付接口。

## 本地运行

### 环境要求

- Node.js 22.13 或更高版本
- pnpm

### 安装与启动

```bash
pnpm install
pnpm dev
```

启动后访问终端中 Vite 输出的地址，默认通常为：

```text
http://localhost:5173
```

### 代码检查

```bash
pnpm lint
```

### 生产构建

```bash
pnpm build
```

构建产物会生成在 `dist/` 目录，可部署到任意静态网站托管服务。

### 本地预览生产构建

```bash
pnpm preview
```

## 主要交互路径

1. 用户进入首页，了解 Curio 的品牌定位和配送保障。
2. 通过关键词搜索、分类或排序缩小商品范围。
3. 点击商品查看评分、价格、描述和库存信息。
4. 从商品卡或详情弹窗将商品加入购物车。
5. 在购物车中调整数量并查看小计。

## 设计与实现取舍

这是一个限时前端实作，优先级集中在商品发现效率、购买路径完整性、品牌可信度和跨设备体验。商品与购物车数据均保存在浏览器当前会话中，刷新页面后会重置。

当前版本未实现以下能力：

- 用户注册和登录
- 后端商品及库存管理
- 购物车持久化
- 订单创建
- 真实支付
- 多语言与实时汇率

这些能力可以在后续接入 API、状态持久化和支付服务时逐步补充。
